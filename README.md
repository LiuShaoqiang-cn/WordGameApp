# 汉字练练看

一款帮助小学一年级学生学习和记忆汉字与拼音对应的消消乐小游戏。

## 游戏简介

「汉字练练看」是一款简单有趣的汉字学习游戏，通过匹配汉字与其对应的拼音，帮助孩子轻松掌握汉字的发音。游戏采用纯 HTML 实现，无需安装，直接在浏览器中打开即可游玩。

## 游戏特色

- 🎮 **消消乐玩法**：在 4x6 的网格中匹配汉字和拼音
- 📚 **丰富字库**：6 个难度级别，共 720 个汉字
- 🎵 **音效支持**：背景音乐和消除音效
- 💡 **提示功能**：每关提供一次提示机会
- ⭐ **精美动画**：粒子效果和流畅的动画
- 🌟 **星空背景**：炫酷的动态星空效果

## 难度级别

| 级别 | 主题 | 数量 |
|------|------|------|
| 第1级 | 基础汉字 | 120个 |
| 第2级 | 日常用品 | 120个 |

| 第4级 | 食物 | 120个 |

| 第6级 | 复合词 | 120个 |

## 如何本地运行

1. 进入 `V3.0.0` 文件夹
2. 双击打开 `index.html`
3. 点击「开始游戏」按钮

## 操作说明

- **鼠标点击**：选择方块进行匹配
- **H 键**：使用提示（每关一次）
- **R 键**：重新开始当前关卡
