# 汉字练练看小游戏需求说明

## 引言

本项目旨在为小学一年级学生开发一个简单的汉字消消乐小游戏，帮助孩子学习汉字和拼音的匹配。游戏采用纯HTML页面实现，无需服务器端数据保存，适合在浏览器中直接运行。

## 游戏概述

- **目标用户**：小学一年级学生（约6-7岁）
- **游戏类型**：消消乐风格的汉字学习游戏
- **平台**：纯HTML页面，主要在电脑上使用谷歌浏览器
- **数据存储**：无需保存数据，每次刷新重新开始

## 游戏规则

### 基本玩法
1. **关卡设置**：游戏分为6个关卡，每个关卡包含12个汉字和对应的拼音
2. **字库选择**：每个关卡从约720个汉字字库中随机选择汉字，难度递进：
   - 第1级：基础汉字（120个）
   - 第2级：日常用品（120个）
   - 第3级：动物（120个）
   - 第4级：食物（120个）
   - 第5级：颜色与形容词（120个）
   - 第6级：复合词（120个）
3. **方块组成**：游戏界面由4行*6列的网格组成，共24个方块，方块随机分布，每个方块显示汉字或对应的拼音，五颜六色
4. **匹配规则**：
   - 玩家连续点击2个方块，一个汉字、一个拼音，可以任意顺序
   - 如果汉字和拼音匹配，则消除这两个方块
   - 消除时有粒子效果和音效
5. **过关条件**：消除所有12对匹配的方块后，显示恭喜提醒和下一关确认按钮
6. **失败重试**：如果无法消除所有方块，可以重试当前关
7. **游戏结束**：完成6关后，显示游戏结束画面

### 特殊规则
- 方块随机分布，确保有足够的匹配机会
- 每个汉字对应一个拼音，匹配必须正确
- 不匹配的点击无效果

### 辅助功能
- **提示功能**：每关可使用一次提示，高亮显示一对匹配的卡片
- **音效功能**：
  - 背景音乐（贝多芬《欢乐颂》旋律）
  - 消除音效（爆炸声）
  - 错误音效
  - 声音开关按钮
- **快捷键**：H键提示，R键重新开始

## 界面设计

### 屏幕布局
- **屏幕比例**：界面居中，最大宽度600px，适配电脑浏览器
- **主要区域**：
  - 开始画面：游戏标题、游戏说明、开始按钮
  - 顶部：关卡显示（当前关卡/总关卡）、耗时显示
  - 中间：游戏区域，4行*6列方块网格
  - 底部：消除进度显示（剩余方块数/总方块数）、进度条、操作提示、提示按钮、声音开关

### 视觉元素
- **背景**：深色星空渐变背景，带闪烁星星动画
- **方块设计**：
  - 多种颜色（12种，分为汉字卡片色和拼音卡片色两类）
  - 方块大小适中，易于点击
  - 显示内容：汉字或拼音，使用清晰易读的大字体
  - 每个方块显示图标（📖汉字、🎵拼音）
- **消除效果**：
  - 缩放+透明度动画
  - 粒子效果（金色小球飞散）
  - 伴随音效
- **过关提醒**：
  - 弹窗覆盖
  - 恭喜文字
  - 用时显示
  - 下一关/重新开始按钮
- **开始画面**：
  - 渐变背景
  - 游戏标题
  - 游戏说明
  - 开始按钮

### 响应式设计
- 主要适配电脑屏幕，界面居中
- 移动端也可正常显示

## 字库设计

### 字库内容
- 总字数：约720个汉字
- 难度递进：6个级别
- 汉字类型：
  - 第1级：基础汉字（一、二、三、人、口、手等）
  - 第2级：日常用品（花、草、树、房、床、桌等）
  - 第3级：动物（猫、狗、鸡、鸭、鱼、鸟等）
  - 第4级：食物（米、面、菜、肉、蛋、糖等）
  - 第5级：颜色与形容词（红、绿、蓝、好、坏、大、小等）
  - 第6级：复合词（学校、老师、学生、朋友、家庭等）

### 数据结构
- 使用JavaScript数组存储，每个条目包含：
  - 汉字（char）
  - 拼音（pinyin）

## 技术要求

### 前端技术
- HTML5
- CSS3（动画、响应式布局、星空背景效果）
- JavaScript（ES6+，无框架依赖）
- Web Audio API（音效）

### 功能模块
- 游戏初始化
- 字库加载（JavaScript数组）
- 方块生成和布局（4x6网格，随机）
- 点击事件处理
- 匹配逻辑
- 粒子效果和音效
- 关卡管理（过关弹窗、重试）
- 耗时和进度显示
- 过关检测
- 提示功能
- 背景音乐播放
- 声音开关控制
- 键盘快捷键支持

### 性能要求
- 页面加载快
- 动画流畅
- 内存占用低

## 用户体验

### 易用性
- 简单直观的界面
- 大按钮，易于点击
- 无需复杂操作

### 教育性
- 帮助记忆汉字和拼音对应关系
- 渐进式难度（6个级别）
- 积极反馈（过关恭喜、动画效果）

### 可访问性
- 高对比度颜色
- 大字体
- 鼠标友好
